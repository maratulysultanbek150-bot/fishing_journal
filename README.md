# 🎣 Fishing Journal

Консольное приложение на Python для ведения личного дневника рыбалки. Проект построен по модульному принципу с разделением пользовательского интерфейса и логики работы с данными.

## 🛠 Технологический стек
- **Python 3.13**
- **JSON** (в качестве локальной базы данных)
- **Git / GitHub** (версионирование и CI workflow)

## 📁 Архитектура проекта
- `main.py` — пользовательский интерфейс, валидация пользовательского ввода, обработка команд меню.
- `storage.py` — модуль работы с файлами, загрузка и сохранение структуры данных в JSON.

## 🚀 Запуск проекта

1. Клонируйте репозиторий:
```bash
git clone https://github.com/твой_ник/fishing-journal.git
```

2. Перейдите в директорию проекта:
```bash
cd fishing-journal
```

3. Запустите главный файл:
```bash
python main.py
```

## ⚙️ Функционал
- Добавление новой записи (вид рыбы, вес, локация, дата)
- Валидация вводимых значений
- Сохранение истории уловов в формат JSON
